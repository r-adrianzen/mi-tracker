📱 Usar en el celular (gratis)
Opción recomendada: GitHub Pages
Las actualizaciones que se hagan al archivo se reflejan automáticamente en tu celular al recargar.

Pasos:
1. Crea cuenta gratis en github.com
2. Nuevo repositorio → llámalo mi-tracker
3. Sube el archivo Tracker_VW_Bora.html
4. Ve a Settings → Pages → Source: main branch
5. Tu URL será: tuusuario.github.io/mi-tracker/Tracker_VW_Bora.html

Abre esa URL en Chrome del celular → Menú ⋮ → "Añadir a pantalla de inicio" → queda como ícono de app.

Los datos se guardan en el celular (localStorage). No se pierden al actualizar el archivo.
Alternativa rápida (sin cuenta): Netlify Drop
1. Entra a netlify.com/drop desde tu PC
2. Arrastra el archivo HTML ahí
3. En 10 segundos tienes una URL pública
Desventaja: la URL cambia cada vez que subas una nueva versión.
